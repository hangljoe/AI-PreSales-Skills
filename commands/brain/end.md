Run the **second-brain** skill in **End My Day** mode.

Sweep today's evidence (calendar, sent mail) if calendar/mail (e.g. Outlook or Google) is connected, then run the short
end-of-day interview in one message and write the 🌙 journal entry to my second-brain folder,
carrying unresolved items forward. On Fridays, also write the weekly rollup.

First run only: bootstraps my second-brain folder, BIG-ROCKS.md, and PROFILE.md interactively
(~10 minutes, or say "skip" for minimal stubs) — every run after that is ~2 minutes.
