Build the **team KPI scorecard** for: **$ARGUMENTS**

Invoke the **presales-metrics** skill in **leader mode** (handbook ch. 22.3 data-driven decisions,
ch. 23 metrics). The skill owns the KPI definitions, formulas, targets and the scorecard layout.
Don't restate or alter any number here. If this wrapper and the skill ever disagree, the skill wins.

Leader-mode rules the skill applies, repeated here only so you can check the output: distribution
across SCs (demos per rep, utilisation) is framed as questions for a 1:1, never as a ranking;
first names only if you ask for them. Individual contributors use the skill directly for their
own scorecard; this command is not routed by `/presales:guide`.
