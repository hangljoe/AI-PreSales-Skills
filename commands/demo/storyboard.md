Build a demo storyboard for: **$ARGUMENTS**

Run the **demo-storyboard** skill. It owns the method; this command is only the entry point.
Paste the discovery summary or key pains in the chat, or let the skill read the deal folder
(`02_discovery-notes.md`, `04_pain-to-value.md`). If your product, capabilities and proof
points are not there yet, the skill asks for them first.

You get the storyboard and run order: persona, Picture Pitch image sequence, one
Tell-Show-Tell module per confirmed pain (10 minutes max each), roles and breaks, and the
Summary Value Close, with every value claim confidence-tagged. Saved to
`05_demo-storyboard.md` if you confirm.

This command does not write the word-for-word script. For that, run
`/presales:demo:script` on the finished storyboard. To rehearse, use demo-dryrun-coach.
