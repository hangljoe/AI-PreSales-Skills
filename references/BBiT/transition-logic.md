# Transition Logic (TrT): Tying Actions to Outcomes

> **Credit.** Study note in our own words. The Theory of Constraints thinking processes, including the Transition Tree, originate with Eliyahu M. Goldratt. This tool, as used here, follows the Black Belt in Thinking (BBiT) programme ([blackbeltinthinking.com](https://blackbeltinthinking.com/)). The method remains the work of its authors.

## What it is

A three-column table that keeps every action tied to the result it should produce.

| Column | Content |
|---|---|
| **Effect** | The outcome needed. What does "done" look like? |
| **Action** | What someone will do. A suggestion that may change. |
| **Logic** | Why this action should produce this effect. |

The logic column is the heart of it. It exposes weak actions, and it gives whoever carries out the action the context to adapt when things change.

## When to use it in PreSales

- Delegating a POC task or a demo build to another SC or a partner.
- Turning PRT intermediate objectives into next steps.
- Planning anything new, where outcomes are easier to define than actions.

## Steps

- [ ] State the reason for the change. No reason, no change.
- [ ] Define the effect: the new state and how you will know it is reached.
- [ ] Choose the best action you can think of for now.
- [ ] Write the logic: why this action will cause this effect.
- [ ] Check the three columns each add something new. Rewrite any column that just repeats another.
- [ ] Review after execution. If the effect did not appear, change the action, not the goal.

## B2B example

| Effect | Action | Logic |
|---|---|---|
| The CFO sees the project as a cost-reduction lever, not an IT expense | Champion presents a one-page value summary in the CFO's quarterly review | The CFO trusts internal numbers in a finance forum more than vendor material |

## Common errors

- **Insufficient action:** plausible at a glance, too weak to cause the effect (a product brochure will not win over a sceptical CFO).
- **Effect written as a completed action:** "The summary has been sent" only restates the action. Name the change you actually want.
- **Perfectionism:** a rough table beats improvising. Adjust as you learn.
