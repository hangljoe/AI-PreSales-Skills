# Critical Thinking: Cause-and-Effect and Prerequisite Logic

> **Credit.** Study note in our own words. The Theory of Constraints thinking processes originate with Eliyahu M. Goldratt. This tool, as used here, follows the Black Belt in Thinking (BBiT) programme ([blackbeltinthinking.com](https://blackbeltinthinking.com/)). The method remains the work of its authors.

## What it is

Every BBiT tool rests on two kinds of logic.

| | Cause-and-effect (sufficiency) | Prerequisite (necessity) |
|---|---|---|
| Claim | A produces B | B cannot happen without A, but A alone does not produce B |
| Read as | "If A, then B" | "In order to B, I must A" |
| Diagram arrow | Vertical | Horizontal |
| Used in | CRT, FRT, Druid, NBR | Cloud, PRT, NCN |

An **assumption** is the "because" that holds a connection together. Surfacing assumptions is what makes a connection open to challenge.

## When to use it in PreSales

- A stakeholder claims "we can't start the POC until X". Test whether X is a true prerequisite or a habit.
- A forecast says "if we demo feature Y, they will buy". Test whether the cause is really sufficient.
- Any time you draw a tree and need to check a single link.

## Steps

- [ ] Write each statement as a complete sentence that is true on its own ("The customer has concerns about data residency", not "data residency").
- [ ] Choose the logic type and draw the matching arrow.
- [ ] Read the link aloud, word for word, in the "If…then" or "In order to…must" form.
- [ ] Add the "because": what must be true for this link to hold?
- [ ] Challenge the assumption: still true today? Required, or just preferred? Is there another route to the outcome?

## B2B example

"In order to run the POC, IT must first approve a production data extract, because realistic results need real data."
Challenge: the evaluation needs *representative* data, not production data. A masked sample meets the need. The prerequisite falls away and the POC can start three weeks earlier.

## Watch for

- Nice-to-haves dressed up as prerequisites. They add delay and remove options.
- Statements that only make sense in context. If a colleague cannot read it alone, rewrite it.
